# Мини-приложение COLIZEUM

Личный кабинет гостя клуба в Telegram: уровень (Silver / Gold / Premium),
прогресс до следующего, акции клуба, рулетка призов и форма для идей.

## Что здесь лежит

```
app/main.py      — веб-API + запуск бота, точка входа
app/bot.py       — Telegram-бот (кнопка мини-приложения + админ-команды)
app/models.py    — база данных, уровни и их пороги
app/prizes.py    — таблица призов рулетки и вероятности
app/telegram_auth.py — проверка подлинности данных из Telegram
webapp/index.html — сама страница мини-приложения (открывается в Telegram)
requirements.txt — список нужных Python-пакетов
Procfile         — команда запуска для Railway
```

Уровни считаются по сумме пополнений клиента за календарный месяц:
Silver — до 5 000 ₽, Gold — 5 000–10 000 ₽, Premium — от 10 000 ₽.
Поменять пороги можно в `app/models.py` (`TIER_THRESHOLDS`).

Пока нет автоматической синхронизации с CRM/POS клуба, суммы пополнений
вносятся вручную через бота (см. ниже) — как только франчайзер даст
доступ к выгрузке или API, это место меняется, остальной код — нет.

## Шаг 1. Бот в Telegram

1. В Telegram напиши **@BotFather** → `/newbot` → следуй инструкциям,
   получишь **токен** вида `123456:ABC-DEF...`.
2. Узнай свой Telegram ID у **@userinfobot** — он понадобится для
   административных команд.

## Шаг 2. Деплой на Railway

1. Загрузи ВСЁ содержимое этой папки (app/, webapp/, requirements.txt,
   Procfile, .env.example, .gitignore) в свой репозиторий на GitHub —
   именно содержимое, а не саму папку как один уровень вложенности.
2. На [railway.app](https://railway.app) → New Project → Deploy from GitHub repo
   → выбери репозиторий. Railway сама увидит `requirements.txt` и `Procfile`.
3. В настройках сервиса (Variables) добавь: `BOT_TOKEN`, `ADMIN_IDS`,
   `ADMIN_SECRET`, `PORT` = `8080`. `WEBAPP_URL` пока оставь пустым.
4. Settings → Networking → Generate Domain, введи порт `8080` — получишь
   публичный адрес вида `https://<имя>.up.railway.app`.
5. Впиши в переменную **WEBAPP_URL** этот же адрес + `/webapp/index.html`,
   например `https://colizeum-miniapp-production.up.railway.app/webapp/index.html`.
6. По умолчанию база — файл SQLite прямо в контейнере; для старта этого
   достаточно. Если Railway пересоздаст контейнер, файл обнулится —
   когда это станет важно, добавь в проекте Railway сервис PostgreSQL
   одной кнопкой, он сам пропишет `DATABASE_URL`, код подхватит его
   автоматически.

## Шаг 3. Проверка в группе

1. Напиши боту `/start` в личных сообщениях — должна открыться кнопка
   мини-приложения, а в нём — тестовые данные (уровень Silver, 0 ₽).
2. Подтверди телефон в мини-приложении (поле в начале страницы).
3. Из своего Telegram-аккаунта (он в ADMIN_IDS) отправь боту:
   `/set_topup +79991234567 12000` (свой тестовый номер и сумму) —
   обнови страницу мини-приложения, уровень должен стать Premium.
4. Добавь пробную акцию: `/add_promo Тестовая акция | Описание акции | silver`
5. Крути рулетку — приз выпадает по вероятностям из `prizes.py`, есть
   суточный кулдаун (`SPIN_COOLDOWN_HOURS`, по умолчанию 24 часа).
6. Когда всё устроит — добавь бота в свою группу и настрой кнопку меню
   бота на мини-приложение через @BotFather → `/mybots` → выбери бота →
   Bot Settings → Menu Button → укажи тот же адрес, что в WEBAPP_URL.

## Дальше

  узнаешь у франчайзера, доступна ли выгрузка/API CRM-системы клуба,
  это место автоматизируется без переделки остального.
- Пороги уровней, тексты акций и таблица призов рулетки — все
  редактируются прямо в коде (`models.py`, `prizes.py`), без базы знаний
  программиста: числа и строки на виду, с комментариями.


## Магазин, отметки, сгорание бонусов, автопосты (обновление октябрь 2026)

**Магазин за бонусы** (вкладка «Магазин»). Каталог и фото — `app/shop_catalog.json`,
при первом запуске товары попадают в базу; дальше цены и наличие меняются в боте:
`/shop`, `/shop_price redbull 300`, `/shop_off monster`, `/shop_on burn гуава`, `/orders`.
Гость оплачивает бонусами → админу приходит заказ с кнопками «✅ Выдан / ↩️ Отменить» →
гость показывает «живой» экран заказа (идут часы, бежит полоса) → админ жмёт «Выдан».
В магазине — только позиции до `SHOP_MAX_BAR_PRICE` (250 ₽ в баре), цены на ~20% выше бара.
Заказ нужно забрать за `SHOP_ORDER_TTL_MIN` (180 минут) — на экране идёт обратный отсчёт.

**Отметка «Я в клубе»** — гость прикладывает фото чека (в кабинете или просто присылает фото
боту), админ жмёт «✅ Засчитать» → `CHECKIN_BONUS` (30) бонусов. Один раз в день.

**Колизы сгорают только без трат** — таймер на `BONUS_TTL_HOURS` (24 ч) запускается, когда на пустом
балансе появляются колизы, и продлевается на сутки любой тратой: покупкой в магазине, списанием,
ставкой в игре или батле. Новые выигрыши срок не продлевают. За 3 часа бот напоминает гостю,
в срок остаток сгорает (сколько сгорело — в `/games`). Тратить можно раз в сутки: либо списание
(50–300), либо заказ в магазине (до 300). Призы рейтингов админ начисляет на карту гостя в CRM —
бот присылает список.

**Приглашения**: +50 (`REFERRAL_BONUS`) за регистрацию друга и +100 (`REFERRAL_ACTIVATION_BONUS`),
когда друг впервые пополнит счёт в клубе (видно после загрузки выгрузки `/import_topups`).
Рейтинг «Самый дружелюбный» — кто привёл больше друзей за месяц, приз `FRIENDLY_PRIZES` (1000).

**Автопосты в группу клуба** — задай `CLUB_GROUP_ID` (бот — админ группы, ID узнать командой
`/chatid` в группе): крупные выигрыши, рейтинг по понедельникам, итоги месяца.

Фронтенд правится в `webapp_src/index.html`, затем `python3 build_webapp.py` собирает
`webapp/index.html` (совместимый со старыми телефонами).

## Новый интерфейс (октябрь 2026)

Главная — клубная карта гостя (баланс, уровень, когда сгорят колизы) и плитки разделов, как в
Яндекс Go: Игры, Магазин, Бронь, Рейтинг, Батл, «Я в клубе», Друзья. Нижней панели больше нет —
в разделах стрелка «назад» (и системная кнопка Telegram). Валюта приложения — **колизы**
(1 колиз = 1 ₽); при списании они переходят бонусами на карту гостя в CRM.
Шрифты Unbounded и Geologica лежат в `webapp/fonts/` (лицензия OFL), с Google Fonts ничего не грузится.

## Серия визитов, профиль игрока, тиммейты, афиша

**Серия визитов** — считаются подтверждённые отметки «Я в клубе» по чеку за календарный месяц.
Награды задаются в `VISIT_REWARDS` (по умолчанию `3:50,6:100,10:hour`: 3 визита — 50 колизов,
6 — 100, 10 — бесплатный час). Колизы начисляются сами, про бесплатный час бот пишет персоналу
«Начисли бесплатный час в CRM…». Прогресс гость видит в плитке «Я в клубе».

**Профиль игрока** — «о себе», ранг и любимые игры (проверка на мат), значки за достижения.
Профиль других открывается по нику из рейтинга и тиммейтов. Очистить чужое описание:
`/profile_reset +79991234567`.

**Тиммейты** — гость создаёт заявку (игра, день, время, сколько человек нужно, комментарий,
не больше 2 активных заявок). Заявка публикуется в чат `TEAM_CHAT_ID` (если не задан —
в `CLUB_GROUP_ID`) с кнопкой «Откликнуться». Откликнувшемуся и автору бот присылает контакты
друг друга. Снять заявку: `/team_del <номер>`.

**Афиша** — только админы. Отправь боту фото с подписью
`/event 01.11 20:00 | Турнир CS2 5×5 | Призовой фонд 5000 колизов`
(без фото — просто текстом). Событие сразу появляется в приложении. `/events` — список
с кнопками «Опубликовать в группе» и «Удалить». Гости жмут «Пойду» и получают напоминание
за 2 часа.
Без фото в афише рисуется постер со значком: он подбирается сам по словам в названии и описании
(футбол, хоккей, UFC, CS2, Dota, FIFA, турнир, марафон, кино, квиз, вечеринка, акция…). Какой значок
выбран, бот пишет сразу после `/event`; если не тот — добавь нужное слово в название или описание.

**Схема зала в брони** — гость отмечает места на схеме (Standart, Bootcamp VIP Pro, Ultra Duo,
PS Zone) и видит характеристики зоны. В заявку персоналу приходят конкретные места,
например «Standart: PC14, PC15; PS Zone: TV3». Занятость онлайн не показывается — её проверяет
администратор. Места и координаты — в `webapp_src/index.html`, блок «схема зала».

## Бесплатные игры — только после пополнения

Рулетка, кости и дайс бесплатно открываются гостям, которые пополняли счёт в клубе:
номер найден в выгрузке CRM (`/import_topups`) — открыто сразу. Остальные видят в разделе
«Игры» кнопку «Проверить пополнение»: в чат персонала приходит заявка с кнопками
«✅ Пополнение есть» / «❌ Не нашёл», администратор сверяет с CRM. Планка — `UNLOCK_MIN_TOPUP`
(по умолчанию 500 ₽), повторная заявка — не чаще раза в `TOPUP_CHECK_COOLDOWN_MIN` (30 мин).
Вручную: `/unlock +7…` — открыть, `/lock +7…` — закрыть. Игры на колизы, магазин и батлы
работают без ограничений.

## Магазин без возвратов

Гость сам заказ не отменяет. Не забрал за `SHOP_ORDER_TTL_MIN` (3 ч) — заказ закрывается,
колизы списываются, эта покупка считается тратой дня. Вернуть колизы может только персонал
кнопкой «↩️ Отменить» под заказом (например, если товара нет в баре).

## Новости клуба с реакциями

Фото с подписью (или текст) `/news Заголовок | Текст` — новость сразу появляется на главной
приложения с кнопками «Круто, жду» и «Не интересно». `/news_list` — последние новости с итогами
реакций и кнопками «Опубликовать в группе» / «Удалить».

## Бонус уровня раз в месяц

Premium — 3000, Gold — 1500, Silver — 500 колизов (`TIER_BONUS=premium:3000,gold:1500,silver:500`).
На главной карточка «Бонус уровня … · месяц» с кнопкой «Забрать»: в чат персонала приходит заявка
«Начисли N бонусов в CRM» с кнопками «✅ Начислил в CRM» / «❌ Отклонить». На баланс приложения
бонус не попадает — не сгорает и не занимает дневной лимит. Один раз в месяц на номер; уровень — по
выгрузке CRM. `/bonuses` — заявки, которые ещё ждут решения.

## «Дымок» — кальяны из приложения (18+)

Плитка «Дымок» на главной → подтверждение 18+ (один раз) → выбор табаков (до 5 в чаше).
Для 1–3 табаков кнопка «Как раскроется» показывает описание микса: пропорции, сладость/кислинка/
свежесть/плотность, раскрытие по этапам, что напоминает, советуемую крепость. Описания встроены
(`app/hookah_data.py`, все 696 сочетаний из 16 табаков) — без ИИ и внешних сервисов.
Заказ: крепость 1–10, холодок, место по схеме зала, когда подать, комментарий. В чат персонала —
сообщение с кнопками «✅ Принял» и «💨 Подан». После подачи гость сам зовёт кальянщика: поменять угли,
добавить холодок, забрать кальян (кнопка «✅ Сделано»). Оплата на стойке; колизы и скидки к кальянам
не применяются. Наличие: `/hookah`, `/hookah_off чизкейк`, `/hookah_on чизкейк`.
Новый табак — добавить в `FLAVORS` и пары в `PAIRS` в `app/hookah_data.py`.

## Списание при большом балансе

При балансе от `WITHDRAW_BIG_BALANCE` (1000) списание открывается одним из двух способов:
сыграть на сумму баланса (ставки в играх и батлах после прошлого списания ≥ баланса) или прислать
фото чека о пополнении в клубе — он приходит в чат персонала с кнопками «✅ Пополнение есть» /
«❌ Отклонить»; подтверждение открывает одно списание на `WITHDRAW_RECEIPT_HOURS` (48 ч).

## Блюр у краёв

При прокрутке контент мягко размывается у верхнего и нижнего края экрана (как в iOS). На старых
телефонах без поддержки размытия остаётся только лёгкое затемнение.

## Кэшбэк за пополнение (главный источник колизов)

Плитка «Кэшбэк за пополнение» на главной и строка в разделе «Игры». Гость прикрепляет фото чека
(или скрин оплаты), номер, на который пополнял, и сумму — и сразу видит, сколько колизов получит по
статусу (Silver 10%, Gold 15%, Premium 20%; без статуса — `CASHBACK_NONE_PERCENT`, по умолчанию 0).
В чат персонала приходит фото с кнопками «✅ Начислить N» / «❌ Отклонить». Если в CRM сумма другая —
`/cashback <номер чека> <сумма>`; `/cashbacks` — непроверенные чеки. Подтверждённый чек начисляет
колизы на баланс, открывает бесплатные игры и списание при большом балансе (на 48 ч).

Бесплатные игры теперь дают 1–10 колизов за попытку: рулетка 1–10 (в среднем ~4), кости 1/3/5/6/8/10
по очкам, дайс 1–10 в зависимости от выбранного шанса.


## Заставка, переходы и разделы клуба (04.11)

**Заставка.** При входе логотип COLIZEUM собирается из двух половин, рисуются × и ○, внизу идёт загрузка
«арены», затем приветствие по никнейму и уровню — и «камера» пролетает сквозь логотип на главный экран.
Карта гостя въезжает в 3D, баланс отсчитывается от нуля, плитки разделов выезжают по очереди.
Полная заставка — при первом входе за день (~3 с), дальше в этот день — короткая (~1,2 с). Есть кнопка «Пропустить».

**Переходы.** Раздел «вырастает» из нажатой плитки на весь экран и сворачивается обратно в неё при возврате.
Остальные экраны въезжают сбоку. Главная запоминает, где гость был при прокрутке.

**Помощь у ПК** (`/api/club/help`). Гость выбирает место и проблему: не включается ПК, лагает, гарнитура/мышь,
вход в аккаунт, нет игры, продлить время, другое. Заявка приходит в чат персонала с кнопками «🏃 Иду» и «✅ Решено».
Когда администратор нажал «Иду», гость видит это в приложении и получает сообщение от бота.
Одна активная заявка на гостя, новая — не раньше чем через 2 минуты.

**Игры в клубе.** Список игр с поиском и жанрами. Список правится в файле `app/club_info.py`
(одна строка — одна игра). Кнопка «Попросить установить» присылает название игры в чат персонала.

**Зоны и ПК.** Карточки зон (Ultra Duo, Bootcamp VIP Pro, Standart, PS Zone) с железом, числом мест,
шкалой мощности и кнопкой «Забронировать» — открывает бронь с подсвеченной зоной.
Железо берётся из `HALL_ZONES` в `webapp_src/index.html`.

## Отыгрыш вместо сгорания за сутки, без бонуса уровня (04.11)

**Отыгрыш.** Колизы живут сутками-«окнами». Окно начинается, когда на балансе появляются колизы;
сумма отыгрыша — баланс в этот момент. Чтобы сохранить колизы, за сутки нужно сделать ставок в играх
и батлах на эту сумму (выигрыш или проигрыш неважен; бесплатные игры не считаются). Если гость часть
колизов списал или потратил в магазине — отыгрывать нужно не больше остатка.
Отыграл — колизы сохраняются, начинается новое окно с текущим балансом. Не отыграл — баланс сгорает,
кроме кэшбэка по чеку и начислений админа (/add_bonus) за это окно: они переходят в новое окно.
За 3 часа до конца окна бот напоминает, сколько осталось отыграть; после сгорания — сообщает, сколько сгорело.
В приложении: строка на карте гостя «Отыграй N · 19 ч» (нажатие открывает игры) и карточка прогресса в «Играх».
При обновлении у всех гостей с колизами начнутся новые сутки отыгрыша.
Списание и магазин — как раньше: до 300 в сутки, одно из двух.

**Правило большого баланса** (от 1000 — списание после игр на сумму баланса или чека) выключено,
его заменил отыгрыш. Вернуть: переменная `WITHDRAW_BIG_BALANCE=1000` в Railway.

**Бонус уровня отключён.** Ежемесячные колизы за Silver/Gold/Premium больше не начисляются —
карточка с главной убрана, только кэшбэк за пополнение по чеку.

**/start** — только кнопка «Открыть личный кабинет». Приглашение друзей — внутри приложения (плитка «Друзья»);
команда /bonus убрана из меню бота, но старые ссылки работают.
